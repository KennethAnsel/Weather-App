# Weather App

This is a simple weather app made using HTML, CSS, and JavaScript.

The app allows users to search for a city and view the current weather details. It uses the OpenWeatherMap API to get live weather data.

## Features

- Search weather by city name
- Shows current temperature
- Shows weather description
- Shows feels-like temperature
- Shows humidity
- Shows wind speed
- Shows pressure
- Shows minimum and maximum temperature
- Aesthetic background image
- Simple and responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## How to Run

Open the `index.html` file in any web browser.

## Project Files

- `index.html` - structure of the app
- `styles.css` - design and layout
- `script.js` - weather API and app logic
- `background.jpg` - background image
